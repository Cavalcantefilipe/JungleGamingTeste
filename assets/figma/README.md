# Imagens do Figma

Origem: [Frontend Challenge, Desktop / Início](https://www.figma.com/design/Ff0SksUi7UFtPWUO8kyNtw/Frontend-Challenge?node-id=2-2).

As quatro imagens PNG de 1254 × 1254 foram extraídas do SVG exportado pelo Figma com autorização do usuário. São os mesmos assets reutilizados nos cards, hero, banners e galeria da referência.

`node scripts/optimize-images.mjs` gera as versões WebP de 900 × 900 em `public/images/figma`. As fontes originais ficam nesta pasta para permitir uma nova otimização sem depender do Figma.
